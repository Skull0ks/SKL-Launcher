Frequently asked questions

Why does Windows warn me about danger?

The installer has no paid digital signature, so SmartScreen does not know the publisher. This happens with most small programs.

Where are the game files?

In %APPDATA%\.skl-launcher, and on Linux in ~/.skl-launcher. You can open it with the “Open game folder” button right in the launcher.

Do I need a Minecraft license?

The launcher runs the game in offline mode by nickname, so it cannot join servers that check licenses. If you like the game, support the developers and buy it.

Which Linux distributions does it work on?

On Ubuntu, Debian, Fedora, Arch, openSUSE, Linux Mint and other popular ones. The installer detects your system, installs Python with tkinter if needed, and adds the launcher to the applications menu with a desktop shortcut. The game needs up-to-date video drivers with OpenGL support.

What if a version does not start?

In the launcher window click “show log” and read the last lines. Most often it helps to remove mods for another game version from the mods folder.

Частые вопросы

Почему Windows предупреждает об опасности?

У установщика нет платной цифровой подписи, поэтому SmartScreen не знает издателя. Это бывает у всех небольших программ.

Где лежат файлы игры?

В папке %APPDATA%\.skl-launcher, а на Linux в ~/.skl-launcher. Открыть её можно кнопкой «Открыть папку игры» прямо в лаунчере.

Нужна ли лицензия Minecraft?

Лаунчер запускает игру в офлайн-режиме по нику, поэтому на серверы с проверкой лицензии он не зайдёт. Если игра нравится, поддержи разработчиков и купи её.

На каких дистрибутивах Linux работает?

На Ubuntu, Debian, Fedora, Arch, openSUSE, Linux Mint и других популярных. Установщик сам определяет систему, при необходимости доустанавливает Python с tkinter и добавляет лаунчер в меню приложений с ярлыком на рабочем столе. Для игры нужны актуальные видеодрайверы с поддержкой OpenGL.

Что делать, если версия не запустилась?

В окне лаунчера нажми «показать лог» и посмотри последние строки. Чаще всего помогает убрать из папки mods моды от другой версии игры.
